# 👗 AI Fashion Design Generator

An AI-powered fashion design generator built with Python, Google Gemini AI, and Streamlit.

## Features
- Select gender, occasion, fashion style, garment, color, and fabric
- Generate a detailed AI fashion design concept
- Output includes design name, concept, silhouette, fabric, color, embellishment, accessories, footwear, styling, and an image prompt

## Tech Stack
- Python
- Google Gemini AI
- Streamlit

## Run Locally
1. Install dependencies:
   `pip install -r requirements.txt`
2. Add your Gemini API key to `.streamlit/secrets.toml`
3. Run:
   `streamlit run app.py`

## Security
Do not upload your API key or `.streamlit/secrets.toml` to GitHub.
